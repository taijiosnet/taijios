# Script corpus for tests/sh/sh_test.zi. Each case starts with "=== name".
# Scripts see $X too: .dis in the Limbo run and .zx in the ZX one, so
# /dis/tiny/rm$X names the program under test. "guest: dis" runs the ZX
# programs of a case in a Dis guest, for programs that read /prog.
# "frozen:" marks a case whose Limbo program is deleted: its golden stays as
# recorded.
# "args:" puts words before the script path on the shell's command line, and
# "noscript" leaves the path out. "input:" is the case's standard input, with
# \n escapes. "gap:" names a known difference and what it waits for; the
# test fails once such a case matches. The lines after "script:" up to the
# next case are the script.
# Scripts see $W, a private work directory holding the fixtures.
